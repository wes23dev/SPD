# Como Rodar

## 🎯 Forma mais fácil

**Clique 2x em `rodar.bat`**

Pronto! O programa roda e mostra os resultados.

---

## 📊 O que ele faz

1. Carrega a imagem `teste.jpg`
2. Aplica filtro de média (mede tempo)
3. Aplica filtro de mediana (mede tempo)
4. Salva as imagens processadas:
   - `saida_media.png`
   - `saida_mediana.png`
